# Code of Conduct

Quoth follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent, welcome newcomers, give and accept constructive feedback gracefully, and focus on what's best for the people using Quoth. Harassment, insults, and personal or political attacks aren't acceptable in any project space.

Report unacceptable behaviour privately to the maintainers (see the repository's contact details or open a confidential security advisory). Reports are handled confidentially, and maintainers may remove comments, commits or contributors that violate this code.
